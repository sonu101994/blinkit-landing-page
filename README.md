# 🛒 Blinkit Clone (HTML & CSS Project)

This project is a **Blinkit-inspired frontend UI** built mainly using **HTML and CSS**.  
The focus of this project is on **layout design and responsiveness**.

A small JavaScript function is added only for the **slider functionality**.

---

## 🚀 Technologies Used

- HTML5  
- CSS3 (Flexbox, Media Queries)  
- JavaScript (only for slider)

---

## 📱 Features

- Responsive design (Mobile, Tablet, Desktop)
- Product grid layout
- Sticky header
- Custom slider (basic JS)
- Clean and simple UI
